# prepare-application-strategy

Relevance: strategy, approach, positioning, how to apply, plan application.

Decide WHAT the application should say before any drafting. Downstream
writing skills consume this strategy.

## Inputs

- opportunity id + evaluation + portfolio evidence + research

## Procedure

1. Confirm MATCH/MAYBE standing (evaluate-opportunity first if stale).
2. Identify: strongest evidence, client's core need, likely problem, credible approach, portfolio picks, requirements needing direct answers, claims to avoid, open questions.
3. Positioning: one-paragraph angle + proposed rate basis.
4. Output a strategy block: evidence_to_use, needs_to_hit, avoid, questions, rate_basis.

## Tools

evaluate via analyze_opportunity, get_portfolio_evidence, research_company, get_user_preferences.

## Failure modes

- Weak evidence overall → recommend not applying rather than bluffing.

## Approval

None. Strategy is a draft artifact.
