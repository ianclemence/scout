# Scout workspace

This directory is YOURS. It holds your working material — never Scout's code.

- `SCOUT.md` — how you want Scout to work for you (tone, rules, defaults).
- `skills/` — your own skills. Drop a folder with a `SKILL.md` here and Scout loads it alongside the 18 built-ins. Same name as a built-in overrides it.
- `imports/` — CVs, job descriptions, notes you want to keep near Scout.

Created once by `scout init`. Never overwritten. Never committed to git
(it lives in your data dir, outside the repository).
