# interview-prep

Relevance: interview, prepare for interview, talking points, questions to ask.

Interview prep strictly from real experience. No fabricated answers.

## Inputs

- opportunity id (+ application id if present)

## Procedure

1. Re-read opportunity + evaluation + portfolio evidence.
2. Produce: likely topics, likely technical questions (from requirements), projects to discuss with 2-line evidence summaries, concise STAR-style examples from REAL history, questions the user should ask, prep gaps (unknowns to study).
3. Every example cites evidence. Gaps marked as gaps, not filled.

## Tools

get_opportunity, get_portfolio_evidence, search_user_evidence, get_user_experience.

## Failure modes

- Requirement with no evidence → "say you haven't done this" guidance, not a script.

## Approval

None. Preparation artifact.
