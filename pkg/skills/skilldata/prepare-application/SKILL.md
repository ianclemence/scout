# prepare-application

Relevance: prepare, full application, complete application, application package, apply, application.

Compose the whole package without submitting. Do not auto-submit.

## Inputs

- opportunity id

## Procedure

evaluate (analyze_opportunity) → research (research_company) → strategy
(prepare-application-strategy) → portfolio (get_portfolio_evidence) →
proposal/cover letter → screening answers → validate_application.

Assemble: proposal, cover letter (if needed), answers, evidence list,
rate, questions, checklist of missing items. Present for review.

## Tools

All application + research + memory tools as needed.

## Failure modes

- Validation blocks → fix or stop; never bypass.
- Missing evidence for core requirement → flag, recommend against.

## Approval

Package is a draft. Submission needs request_approval + human approval.
