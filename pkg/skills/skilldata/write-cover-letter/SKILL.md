# write-cover-letter

Relevance: cover letter, cover-letter, introduction letter.

Cover letters derived from strategy + evidence. Never a proposal copy.

## Inputs

- opportunity id + strategy

## Procedure

1. draft_cover_letter for the evidence-grounded base.
2. Reshape: motivation + fit narrative (why this work, why this person), distinct from the proposal's approach section.
3. Same truthfulness rules as write-proposal. Concise.

## Tools

draft_cover_letter, validate_application, get_user_profile.

## Failure modes

- Source needs proposal only → say so, don't force a letter.

## Approval

Draft only.
